Overview

myCPU 是一个可在浏览器中体验的 RISC-V 系统模拟器工作台，把 OS demo、CPU 观察、AI accelerator 和 runtime labs 放在同一个入口。

Try the Console

打开控制台后选择 workload，运行 demo，并在 terminal、pipeline、register、memory、profile 和 device counters 之间切换视角。

Architecture

核心链路由 CPU、AddressSpace、Bus、RAM / Device、debug snapshot 和浏览器控制台组成，页面展示来自这些真实运行数据。

OS Bring-up

xv6 shell、Linux serial console 和 interactive_os 组成系统运行路线，展示 boot log、shell marker、monitor 命令和 UART 交互。

AI Accelerator

AI accelerator 路线展示 graph package、MMIO doorbell、DMA、scratchpad、compute、completion、KMVAI marker 和 profile counters。

JIT / DBT Prototype

JIT / DBT runtime lab 展示 translation、host executable、cache hit / miss、fallback、invalidation 和 summary stats。

Verification

默认门禁包括 cd frontend && node --test、cd myCPU && make test 和 make test-pipeline。

Roadmap

Post-Wave 7 新主线是标准 Debian / Alpine 镜像级平台，以及用户自定义 AI 任务和更接近商用 NPU 的性能模型。
