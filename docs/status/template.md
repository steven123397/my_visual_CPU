# 状态文档模板

## 文档定位

本文档用于记录：

- 当前状态
- 当前仍然有效的风险 / 限制
- 少量关键历史节点
- 下一步工作

默认不保留完整执行 checklist、已完成的逐项任务流水账或大段阶段性 TODO 历史。

## 关联文档

- 相关设计：
- 当前计划：
- 已完成计划：

## 目标 / 主题

用 1 到 3 句话说明这份文档跟踪的对象是什么，它的工程目标是什么。

## 当前状态

列出当前已经稳定成立的事实：

- 已落地的核心能力
- 当前稳定输出 / 回归标记
- 当前已形成的主路径与负向路径

## 关键历史节点

只保留少量真正重要的节点，例如：

- 首个里程碑何时完成
- 哪一批 correctness 修复何时落地
- 哪条独立负向回归何时接通
